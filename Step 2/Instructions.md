# Step 2: Core workflow management

## Instructions

Extend the application with a basic workflow-management feature.

Your task is to:

1. Create a `Workflow` entity with:

   * Name
   * Description
   * Status
   * Owner
   * Created and updated dates
2. Allow authenticated users to:

   * View workflows
   * Create workflows
   * Edit workflows
   * Delete workflows
3. Add search, filtering and sorting.
4. Add clear loading, empty and error states.
5. Validate input on both the client and server.
6. Add any required database migrations and tests.
7. Submit the work through a focused pull request and deploy it after approval.

Keep the feature simple and avoid unrelated refactoring.

## Success criteria

The task is complete when:

* Users can create, view, edit and delete workflows.
* Search, filtering and sorting work correctly.
* Invalid data cannot be saved.
* Loading, empty and error states are clear.
* Database migrations work on a clean database.
* Appropriate tests cover the main behaviour.
* The application builds and deploys successfully.
* The pull request is focused and clearly documented.
* No secrets or unrelated changes are committed.
